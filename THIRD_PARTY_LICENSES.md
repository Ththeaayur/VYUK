# Third-Party Licences — VYUK's Components

VYUK runs on third-party components. Most are permissive (Apache-2.0 /
MIT / BSD), but not all: the GUI framework and a few libraries are
copyleft — LGPL, MPL, and (through kokoro-onnx's phoneme engine) GPL.
Those get their own section below, with the compliance steps VYUK
takes for each; do not assume "everything is Apache/MIT". The Python
packages come from `requirements.txt`; the model and voice files are
bundled with the installer and are downloaded by
`core/voice/local_assets.py` only when running from source or repairing a
damaged pack.

Last audited: v5.88 (CC-1 ship-gate licence audit; audit still exits 1 — see Cesium row and the v5.88 gate report, never read as licence-clean)
