# NET Licence Read — Wave 9 Build 6

Own code, standard library only — in fact, the network
module imports nothing beyond ``__future__`` annotations,
and the tools coordinator imports only ``json``,
``pathlib``, and the network module itself.

No third-party code, package, model, dataset, font, sound
pack, feed, or service is introduced by this build. No
network is scanned, probed, connected to, or resolved,
so no network-service terms, carrier terms, or
connection-data licence question is engaged. No address
is resolved and no hostname is looked up anywhere in the
module, the tools, or their descriptions.

Nothing here is a network scanner, a port scanner, a
connection tool, or a discovery service, and nothing in
this build may be described as one.
