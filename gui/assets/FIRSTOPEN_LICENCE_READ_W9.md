# First-open continuous opt-in — licence read

Own code, standard library only (`dataclasses`, `pathlib` in
the choice module; `json`, `pathlib` in the tool
coordinator). No third-party code, package, model, dataset,
font, sound pack, or feed is introduced by this build, so no
licence blocker arises in this build itself.

What this build deliberately does NOT clear, and does not
claim:

- No continuous capture feature is cleared here. Screen
  memory, clipboard history, and any continuous feature are
  separate Wave 9 TENSION builds under their own route, and
  each of those builds still needs its own terms and licence
  position before it ships anything.
- No PF-3 global delete-everywhere rule is cleared or
  claimed. The per-feature delete in this build deletes
  only the regular files inside one caller-named folder; it
  is not a global rule and must never be described as one.
- No suggestion-cards grant is reused. The Wave 8
  suggestion-cards scope opens suggestion cards only; the
  continuous-display scope in this build is a separate
  record, and the two must never be treated as one choice.
- A future item that introduces third-party code still
  needs its own primary licence read before any separate
  human application of that item.
