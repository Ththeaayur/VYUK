# IOT-L licence read — Wave 9 Build 3

Own code, standard library only. No third-party code,
package, model, dataset, font, sound pack, feed, or
service is introduced by `core/iotl.py` or
`core/iotl_tools.py`, so no third-party licence
question is engaged by this build.

No device, network, or service terms question is
engaged either: nothing here reaches a device, polls a
device, controls a device, scans a network, resolves an
address, or talks to any external service. Device
names, address labels, network labels, state words,
and timestamps are caller-supplied strings, recorded
as given, never fetched from a device or a service.

Verdict: no licence read owed for this build. Any
future build that actually reaches a device, polls a
device, controls hardware, or talks to a vendor
service needs its own primary licence/terms read
before it is made — this note clears nothing of that
kind.
