# ACCESS licence note — Wave 9 Build 5 (accessibility deltas)

Own code, standard library only. No third-party code,
package, model, dataset, font, pack, feed, or service
is introduced by this build, so no new licence question
is engaged and no licence read is owed for it.

No screen-capture, OCR, or sensor code is used, and no
live screen is read: the window description works only
on a caller-supplied snapshot. No data about a
disability is collected, inferred, or stored: the
preference record carries a plain-language setting label
and an enabled flag only, and any disability, health,
score, or inferred field refuses whole.

Nothing in this build is a medical, diagnostic, or
capability claim, and nothing here is presented as
conformance with any accessibility guideline — that
claim, if ever made, would need its own evidence and
its own review, and it is not made here.
