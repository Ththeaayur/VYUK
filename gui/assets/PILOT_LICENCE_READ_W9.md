Descriptors and records only, for the buildable PILOT
slices of §13 Parts 15 (workshop), 16 (student), and 17
(dev). Nothing is executed, nothing is read live,
nothing is deployed, and nothing is signed.

## Licence verdict: own code, no licence engaged

- `core/pilot.py` and `core/pilot_tools.py` are
  own code, written for this build. They import nothing
  beyond `__future__` annotations (module) and the
  standard library (`json`, `pathlib`) plus the own
  pilot module (coordinator).
- No third-party code, package, model, dataset, font,
  pack, feed, or service is bundled, vendored, linked,
  or shipped by this build. No third-party terms
  question is engaged, because nothing connects,
  nothing reads a repo, file, portal, or device, and
  nothing runs.
- No P15 / P16 / P17 item's own licence question is
  cleared by this note: the CAD tool licence for P15-1,
  the language-tier licences for P16-24 / R5-E, and any
  third-party tool a future slice might drive all stay
  OWED, to be primary-read before any build that uses
  them. This build uses none of them.
- The shipped Study tools are reused by reference only
  (the study-session descriptor builds on, and does not
  duplicate, the shipped Study edition); no Study code
  is copied or changed here.
