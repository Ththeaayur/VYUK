# FEEL LICENCE READ — Wave 8 Build 4 (feel, non-veto only)

Own code, standard library only (math, hashlib, io, wave, re).
No third-party code, package, model, font, sound pack, sample,
feed, or data is introduced by this build, so no per-asset
licence read is owed by this build itself — except the two
sightings this build deliberately leaves OWED, below, and the
per-pack rule that keeps every pack out until its own primary
read exists.

- Aura orb licence sighting: OWED. No orb file, orb code
  change, or orb asset is introduced here; the orb mapping
  is data only (measured level -> scale/glow/pulse). Nothing
  in this build claims the orb, bundles it, or depends on a
  sighting that does not exist. The mapping waits on the
  sighting; it does not replace it.
- Orbitron OFL sighting: OWED, per family. No Orbitron file
  exists in the tree and no primary OFL sighting was read
  in this build, so the font stays unbundled and only the
  HUD language (own copy) builds. Orbitron is one family,
  not a blanket font clearance: no other family's sighting
  clears it, and no other family is cleared by this note.
  Space Grotesk pairing is VETOED and is not used here,
  even though a Space Grotesk file sits in the tree from
  an earlier font audit — presence in the tree is not
  clearance, and this build does not touch that file.
- Procedural own sounds (sfxr method): no licence engaged.
  The sounds are generated from parameters by own code;
  no sample, no ripped movie/game audio, and no third-party
  sound library is used. A sound PACK is only ever a ledger
  record, and only when the caller supplies a primary read
  (source + licence text naming a CC0 / CC-BY licence);
  a pack without one is refused in code, never bundled,
  never claimed. A future build that actually bundles a
  pack needs that pack's own primary read before it builds
  — this ledger does not grant one.
- HUD rules and HUD language: own copy, own colour values.
  No copied HUD art, no Marvel asset or trademark, no
  character voice, no catchphrase, no claim to be the
  fictional assistant is introduced.

Vetoed feel (Charon, M4, earcon family, F6 signatures, Space
Grotesk pairing) is refused in code by the feel validator
and is not present anywhere in this build. No face, no fake
data, no paid asset is introduced.

Verdict: OWN CODE, STDLIB ONLY — no licence blocker in this
build itself. The orb and Orbitron sightings stay OWED and
gate any future orb-asset or font-bundling work, exactly as
Wave 8 Build 3 recorded them.
