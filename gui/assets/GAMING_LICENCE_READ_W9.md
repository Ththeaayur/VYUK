# Gaming Licence Read — Wave 9 Build 7 (P14)

Own code, standard library only — in fact, the gaming
module imports nothing beyond ``__future__`` annotations,
and the tools coordinator imports only ``json``,
``pathlib``, and the gaming module itself.

No third-party code, package, model, dataset, font, sound
pack, feed, or service is introduced by this build. No
game is read, controlled, automated, or observed, so no
game licence, end-user licence, or anti-cheat terms
question is engaged: nothing here touches a game at all.

No GPL tool is bundled, vendored, linked, or shipped by
this build. OBS (GPL-2.0), FFmpeg GPL builds with libx264,
and LosslessCut (GPL-2.0-only) are named only, in
drive-only notes, with their licence labels as recorded
in the plan (build_flow_v6.md, Wave 9 P14 line) or as
supplied by the caller for an unnamed tool — never
upgraded to a clearance, never softened, and never
presented as shipped, integrated, or runnable by Nova.
A caller-supplied licence label for a plan-recorded GPL
tool that does not match the plan-recorded label refuses
the whole note.

Nothing here is a game reader, a memory reader, an
injector, a cheat, an anti-cheat evasion, an automation
runner, or a bundled media tool, and nothing in this
build may be described as one.
