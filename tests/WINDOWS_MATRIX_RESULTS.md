# Windows Matrix Results — VYUK (v5.50, item 40 — FIELD record)

Blank results-recording template for the Windows validation
matrix in `WINDOWS_VALIDATION_MATRIX.md` (same folder). One row
per combination of brain × display scaling × monitor setup:
4 brains × 3 scalings × 2 monitor setups = 24 rows.

Brains are the engines `core/brain/brain.py` can select: Gemini Live,
Groq, Local and Lite. Scaling is the Windows display scaling for
the run; Monitors is a single display, or a second monitor
connected and set to "Extend".

Every Date / Build / Machine / Result / Notes cell below is
EMPTY on purpose: this file is a scaffold, not a record. A cell
is filled only when that exact combination has actually been
run on a real Windows machine, following the Runbook section of
`WINDOWS_VALIDATION_MATRIX.md`. Never backfill a row from
memory, from another row, or from a different build.
